# COURT 19 — V1.01-A

Pré-lançamento de estudo para Windows x64, destinado ao dump próprio de NBA LIVE 19 para PS4, Title ID CUSA11355.

## Alterações

- Runtime atualizado para shadPS4 0.21.1.0, revisão upstream `4788f0b`.
- Launcher COURT 19 com ícone próprio incorporado.
- Testes locais relataram melhora de estabilidade e apresentação gráfica.

## Limitações conhecidas

Persistem artefatos gráficos, principalmente na rede da cesta. Somente CUSA11355 foi validado; outros Title IDs não foram testados. Esta versão não inclui tradução PT-BR.

## Requisitos e conteúdo

Windows x64 e suporte Vulkan. O pacote não inclui o jogo, firmware, módulos de sistema, chaves, saves, logs ou tradução. Use seu próprio dump e arquivos de sistema que você tenha direito de usar. Leia o README incluído no pacote Windows.

O arquivo `COURT19-V1.01-A-Launcher-Source.zip` contém as fontes do launcher e os recursos necessários. A fonte exata do runtime shadPS4 está identificada em `SHADPS4-SOURCE.txt` dentro do pacote Windows.

COURT 19 é um projeto de estudo independente, sem afiliação com EA, NBA ou Sony.
