# COURT19-PTBR-Patch — código-fonte

Fontes do instalador visual e da aplicação do patch diferencial PT-BR para NBA LIVE 19 CUSA11355.

O pacote contém somente os identificadores e textos traduzidos do patch, metadados de estrutura, código do instalador/aplicador e bibliotecas com avisos de licença. Ele não inclui o banco completo do jogo, arquivos BIG, dump, firmware, módulos ou chaves.

Para reconstruir o instalador visual, use Windows x64 e .NET 10 SDK com `installer-src/Installer.csproj`. O instalador publicado também usa o Node.js portátil incluído no pacote binário; a fonte do runtime Node está disponível no projeto oficial Node.js.

A tradução é um patch de fã não oficial. A distribuição de textos derivados pode envolver direitos autorais; COURT 19 não é afiliado nem endossado pela EA, NBA ou Sony.
